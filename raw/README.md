# raw/

Sources the wiki may keep. This directory is committed and published with the repository.

Add a file when Piotr is willing to publish it: notes he wrote, or a document whose licence allows republication.

A copyrighted or paywalled source stays a link plus his notes. The page lists that source by title and, when there is a public URL, by that URL. The full text stays out of the repository.

Ingest one source at a time. The ingest skill shows a plan and waits before it writes pages.
